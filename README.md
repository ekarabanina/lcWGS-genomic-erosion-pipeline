# lcWGS-genomic-erosion-pipeline
A pipeline for low-coverage whole-genome sequencing analyses to study genomic erosion applied to Finnish golden eagles (Aquila chrysaetos).
A visualization of the pipeline is available at Bioinformatics pipeline.pdf. 

Aims of this repository:
1. Ensure transparency and replicability of data analyses.
2. Assist researchers conducting similar analyses. 
3. Archive scripts for future reference and reuse.

   
All cluster jobs were performed on Puhti*, CSC supercomputer, Finland: https://csc.fi/en/ 
*Puhti was replaced with Roihu supercomputer in Autumn 2026, therefore, module-loading commands may differ.
